End-to-End Architecture & GitHub Hosting

This dashboard is powered by a reproducible Python + SQLite analytical pipeline (src/pipeline.py) and modular SQL queries (sql/analytics_queries.sql). Every push is verified by GitHub Actions CI (.github/workflows/ci.yml).

# Reproduce locally & run automated tests
python3 data/generate_data.py
python3 src/pipeline.py
python3 -m unittest discover -s tests -v
# Deploy live on GitHub Pages
Settings → Pages → Deploy from branch: main (/docs)
